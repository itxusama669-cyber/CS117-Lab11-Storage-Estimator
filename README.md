# Storage Estimator - Main Version

## Purpose
This Python program estimates a file's storage size in megabytes (MB) and converts it to gigabytes (GB).

## Requirements
- Python 3 installed on your computer.

## How to Run
Open a terminal in this folder and run:

```bash
python storage_estimator.py
```

On some Windows installations, use `py storage_estimator.py`.

## Example
```text
Enter file size in megabytes (MB): 2048

Storage Estimate
File size: 2048.00 MB
File size: 2.0000 GB
```

The conversion uses 1024 MB = 1 GB. Negative values and non-numeric input are handled with an error message.
